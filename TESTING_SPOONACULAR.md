## Testing With API Key (Full Feature)

### Setup API Key

**Option 1: Environment Variable**
```bash
export SPOONACULAR_API_KEY='your_actual_api_key'
python manage.py runserver
```

**Option 2: Temporary Settings (Development Only)**
Edit `campuscrave/settings.py`:
```python
SPOONACULAR_API_KEY = 'your_actual_api_key'
```

## Performance Notes

### API Call Timing
- Each ingredient = 1 API call
- 4 ingredients = ~2-4 seconds total
- Results cached in database
- No API calls on subsequent views

### Optimization
- Keep ingredient lists concise (4-8 items)
- Use common ingredient names
- API only called on create/edit with ingredient changes

## Troubleshooting

### Issue: No nutrition data generated
**Check**:
1. Is API key set? `echo $SPOONACULAR_API_KEY`
2. Check server logs for errors
3. Verify API quota on Spoonacular dashboard
4. Test with simple ingredients like "chicken, rice"

### Issue: Incorrect dietary tags
**Solution**:
- Auto-suggestion is a helper, not mandatory
- Sellers can manually override any tag
- Complex recipes may need manual classification

### Issue: Missing allergens
**Note**:
- Detection based on common keywords
- May not catch all allergens
- Sellers should verify and add manual notes if needed
